# skills/ — Instructions spécialisées pour Claude Code

Chaque fichier ici cible un domaine du projet. Claude Code doit lire le fichier correspondant au domaine sur lequel il travaille, en plus de `CLAUDE.md` et des documents `docs/`/`design/` pertinents.

- `frontend.md` — Next.js, design system, Three.js, i18n, responsive
- `backend.md` — NestJS, structure des modules, conventions API
- `financial-engine.md` — implémentation et tests du moteur de calcul
- `ai.md` — intégration IA, prompts, garde-fous
- `payment.md` — intégration FedaPay, webhooks, sécurité
- `database.md` — schéma, migrations, conventions PostgreSQL
- `testing.md` — stratégie de tests, couverture attendue
