# i18n FR/EN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre Ça tient ? utilisable de bout en bout en anglais (`/en/...`), sans changer le parcours français.

**Architecture:** Pages publiques sous `app/[lang]` (layout racine par langue, `next/root-params`), `proxy.ts` qui réécrit les adresses sans préfixe vers `fr` et redirige `/fr/...`. Dictionnaires TypeScript (`fr` = forme de référence, `en` typé dessus), lus par `getI18n()` côté serveur et `useI18n()` côté client. L'API stocke `Idea.locale` et l'utilise pour l'IA, la synthèse et le retour de paiement.

**Tech Stack:** Next.js 16.3.8 App Router, React 19, NestJS 12, Prisma 7.10, vitest, playwright-core (scratchpad).

**Spec:** `docs/superpowers/specs/2026-10-03-i18n-fr-en-design.md`

## Global Constraints

- Français à la racine, anglais sous `/en`, mêmes segments (`/en/commencer`) ; `/fr/...` → 308 vers le chemin sans préfixe.
- Pas de redirection selon le navigateur ; bandeau `LanguageSuggestion`, cookie `ct_lang_hint` (1 an).
- Admin hors `[lang]`, en français uniquement.
- Aucune dépendance de production ajoutée ; vitest en devDependency du web seulement.
- Un chiffre affiché ne vient jamais de l'IA (`CLAUDE.md` #3) ; `approxEurFromXof` avec `XOF_PER_EUR = 655.957`.
- Devise par défaut : EUR en anglais, XOF en français.
- `Idea.locale` : `"fr" | "en"`, défaut `"fr"` ; migration via `prisma migrate diff`.
- Serveurs de vérification sur 3011 (API) / 3012 (web), arrêt par PID exact ; ne jamais lire `apps/api/.env`.
- Web buildé avec `NEXT_PUBLIC_API_URL=http://localhost:3011` pour les vérifications (variable inlinée au build).
- Commentaires en anglais, seulement sur les décisions non évidentes.

## Review Focus

1. Requête vers `/en` exact (sans slash final) et `/en?x=1` : doit rester anglais, pas `/fr/en`. → test `resolveLocaleRoute` Task 2.
2. Chemins `/english`, `/enfant` : ne doivent pas être pris pour l'anglais. → test Task 2.

5. Synthèse déjà stockée en français puis même idée relue avec locale `en` : régénérée, jamais servie telle quelle. → test `factsHash` Task 7.

`locales.ts` :

```ts
export const LOCALES = ["fr", "en"] as const;
export type Locale = (typeof LOCALES)[number];
export const DEFAULT_LOCALE: Locale = "fr";

export function hasLocale(value: string): value is Locale {
  return (LOCALES as readonly string[]).includes(value);
}
```

`locale-route.ts` :
```ts
import { DEFAULT_LOCALE, type Locale } from "./locales";

const PREFIX = /^\/(en|fr)(?=\/|$|\?|#)/;

export function stripLocale(pathname: string): { locale: Locale; path: string } {
  const match = pathname.match(PREFIX);
  if (!match) return { locale: DEFAULT_LOCALE, path: pathname };
  const rest = pathname.slice(match[0].length);
  return { locale: match[1] as Locale, path: rest.startsWith("/") ? rest : `/${rest}` };
}

// French lives at the root, English under /en: one address per page and language.
export function localizedPath(path: string, locale: Locale): string {
  const { path: bare } = stripLocale(path);
  if (locale === DEFAULT_LOCALE) return bare;
  return bare === "/" ? "/en" : bare.startsWith("/?") || bare.startsWith("/#") ? `/en${bare.slice(1)}` : `/en${bare}`;
}

export type LocaleRoute =
  | { action: "next" }
  | { action: "rewrite"; pathname: string }
  | { action: "redirect"; pathname: string };

export function resolveLocaleRoute(pathname: string): LocaleRoute {
  const match = pathname.match(PREFIX);
  if (match?.[1] === "en") return { action: "next" };
  if (match?.[1] === "fr") return { action: "redirect", pathname: stripLocale(pathname).path };
  return { action: "rewrite", pathname: pathname === "/" ? "/fr" : `/fr${pathname}` };
}
```

`proxy.ts` :
```ts
import { NextResponse, type NextRequest } from "next/server";
import { resolveLocaleRoute } from "@/i18n/locale-route";

export function proxy(request: NextRequest) {
  const route = resolveLocaleRoute(request.nextUrl.pathname);
  if (route.action === "next") return NextResponse.next();
  const url = request.nextUrl.clone();
  url.pathname = route.pathname;
  return route.action === "redirect" ? NextResponse.redirect(url, 308) : NextResponse.rewrite(url);
}

export const config = {
  // Admin, Next internals, metadata routes and files with an extension never carry a locale.
  matcher: ["/((?!_next|admin|robots\\.txt|sitemap\\.xml|icon|apple-icon|.*\\.[a-zA-Z0-9]+$).*)"],
};
```
