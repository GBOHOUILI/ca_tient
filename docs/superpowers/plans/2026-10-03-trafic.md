# Suivi du trafic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compter les pages vues du site public et les restituer dans un onglet « Trafic » de l'admin, avec graphiques.

**Architecture:** Le navigateur envoie une vue par changement de page (`POST /analytics/pageviews`) ; l'API normalise et stocke dans `PageView` (chemin, langue, appareil, pays estimé, source) ; `GET /admin/traffic` agrège en mémoire avec des fonctions pures ; la page admin réutilise `DailyChart`, `BarTable`, `Kpi`.

**Tech Stack:** NestJS 12 + Prisma 7.10 + vitest ; Next.js 16 + recharts.

**Spec:** `docs/superpowers/specs/2026-10-03-trafic-design.md`

## Global Constraints

- Ni IP, ni user-agent complet, ni fuseau, ni référent complet stockés.
- `visitorId` dans `localStorage` (`ca-tient:visitor`), exclusion `ca-tient:no-track`, `navigator.webdriver` jamais compté.
- Jours en UTC (comme le reste du dashboard), heures en heure du Bénin (UTC+1).
- Graphiques à une seule série, émeraude.
- Migration additive via `prisma migrate diff` ; serveurs de vérification 3011/3012.

## Review Focus

1. Chemin `/analyse/<cuid>` : jamais stocké tel quel. → test `normalizePath`.
2. `utm_source` en majuscules (`WhatsApp`) et référent `l.facebook.com` : même source que `facebook`. → test `trafficSource`.
3. Visiteur vu avant la période : pas compté comme nouveau. → test `trafficStats`.
4. Vue à 23h30 UTC : heure du Bénin 0h. → test `trafficStats`.
5. Fuseau inconnu ou absent : pays `null`, la vue est quand même enregistrée. → test intégration.
