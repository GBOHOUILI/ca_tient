## Planning indicatif — première semaine

| Jour | Objectif | Travail |
|---|---|---|
| 1 | Cadrage + fondation | Positionnement, schéma des données, structure du projet, landing |
| 2 | Moteur financier | Formules, modèles, tests unitaires, premiers résultats |
| 3 | Parcours + IA | Formulaire guidé, extraction des variables, validation utilisateur |
| 4 | Scénarios | "Et si… ?", scénarios prudent/réaliste/ambitieux/crise |
| 5 | Analyse complète | Rapport complet, préparation paiement |
| 6 | Paiement + déploiement | Paiement, vérification serveur, protection de l'accès, mise en ligne |
| 7 | Tests | Tests techniques + tests avec quelques utilisateurs réels |
